# macOS TUN 用户体验优化 - 快速参考

## ✅ 新增功能

### 1. 权限状态指示器

**位置**: TUN 开关旁边

**状态**:
- ⚠️ 需要权限（红色）
- ⏳ 检查中...（黄色）
- ✅ 已就绪（绿色）

### 2. 权限获取按钮

当用户点击 TUN 开关且权限不足时：

```
┌─────────────────────────────────┐
│  开启TUN需要管理员权限           │
│                                 │
│  ┌─────────────┐ ┌───────┐    │
│  │  获取权限   │ │  取消  │    │
│  └─────────────┘ └───────┘    │
└─────────────────────────────────┘
```

### 3. 去设置按钮

当 TUN 启动失败且权限不足时，错误提示包含"去设置"按钮，直接打开系统设置。

### 4. 兜底方案

当 TUN 启动失败时，询问是否切换到系统代理模式：

```
┌─────────────────────────────────┐
│  TUN 模式启动失败                │
│  是否切换到系统代理模式？         │
│                                 │
│  ┌─────────────┐ ┌───────┐    │
│  │ 切换到代理  │ │  取消  │    │
│  └─────────────┘ └───────┘    │
└─────────────────────────────────┘
```

## 🎯 用户流程

### 正常流程
1. 用户点击 TUN 开关
2. ✅ 已就绪 → TUN 启动成功

### 权限不足流程
1. 用户点击 TUN 开关
2. ⚠️ 需要权限 → 弹出权限提示
3. 用户点击"获取权限"
4. macOS 认证对话框弹出
5. 用户授权 → ✅ 已就绪

### 兜底流程
1. 用户点击 TUN 开关
2. TUN 启动失败
3. 弹出提示：是否切换到系统代理模式？
4. 用户点击"切换到代理模式"
5. 系统代理模式启动成功

- **Windows**: `ms-settings:users`
